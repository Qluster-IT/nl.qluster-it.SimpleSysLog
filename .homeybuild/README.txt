Simple (Sys) Log.

FEATURES
* Live dashboard widgets with search, Level and Date filters, optional paging and light/dark modes.
* Customize designs and themes, including Compact, Journal and Console designs and Ocean, Forest, Sunset and Console themes.
* Share designs and themes as TWFs through Templates and the Widget Exchange, with light and dark preview images.
* Use signed Web widget links to show logs on an Android dashboard.
* Create temporary CSV, Excel or JSON download links from Advanced Flow.

This app makes it possible to add logging and/or notifications to your Flows.
Optionally a log can have, next to its message, an App/group, severity and facility.

You can also connect to multiple Syslog-clients to a) send specific message and b) have all default messages (with certain severities) send there.

And last but not least, you can create Syslog Server device, to let other Syslog clients connect to, which will be written into the Simple (Sys) Log.

Logs are stored in files rather than memory, allowing a larger logbook.

The settings page has a Syslog-style interface, in which you can:
* Rotate the screen for a better view on a Mobile or other landscape-screen device.
* Search and filter specific messages, dates, etc.
* Hide or move columns.
* Save the filters or columns as default.
* Download the complete Log as nicely formatted Excel, Csv or JSON, in the Mobile App, Developertools or within flows.


You can use the API endpoints to access the log.

Better Logic Library is supported (optional for basic logging, required for the full interface, exports and widgets). Use BLL coding in supported Flow message and group fields; see the Better Logic Library app settings for instructions.
