새롭고 개선된 Simple (Sys) Log.

이 앱은 플로우에 로깅 및/또는 알림을 추가할 수 있게 해줍니다. 선택적으로 로그에는 메시지 외에 앱/그룹, 심각도 및 시설을 포함할 수 있습니다.

여러 Syslog 클라이언트에 연결하여 a) 특정 메시지를 보내거나 b) 모든 기본 메시지(특정 심각도를 가진)를 보낼 수 있습니다.

그리고 마지막으로, 다른 Syslog 클라이언트들이 연결할 수 있도록 Syslog 서버 장치를 생성하면, 이는 Simple (Sys) Log에 기록됩니다.

이 새로운 버전은 메모리가 아닌 파일에 로그를 저장하여 이전보다 훨씬 더 큰 로그를 제공합니다.

완전히 새로워진 설정 페이지에는 Syslog 스타일의 인터페이스가 있으며, 여기서 할 수 있는 것들은 다음과 같습니다:
* 모바일이나 다른 가로 화면 장치에서 더 나은 시야를 위해 화면 회전.
* 특정 메시지, 날짜 등을 검색하고 필터링.
* 열 숨기기 또는 이동.
* 필터나 열을 기본값으로 저장.
* 모바일 앱, 개발 도구 또는 플로우 내에서 완전히 포맷된 Excel, Csv 또는 JSON 형식으로 로그 다운로드.

API 엔드포인트를 사용하여 로그에 액세스할 수 있습니다.

예제와 정보를 위해 커뮤니티 포럼의 주제를 참조하세요.

* 이 앱은 여전히 독립형 앱으로 작동합니다. 그러나 모든 기능과 새로운 인터페이스를 활성화하려면 Better Logic Library 앱이 설치되어야 합니다.
