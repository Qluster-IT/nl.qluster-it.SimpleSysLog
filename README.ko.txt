Simple (Sys) Log.

주요 기능
* 검색, 수준 및 날짜 필터, 선택적 페이지 이동, 밝은/어두운 모드를 지원하는 실시간 대시보드 위젯.
* 간결, 일지, 콘솔 디자인과 바다, 숲, 일몰, 콘솔 테마 등 디자인과 테마 사용자 지정.
* 템플릿과 Widget Exchange에서 밝은 모드와 어두운 모드 미리보기 이미지가 포함된 TWF로 디자인과 테마 공유.
* Homey Web Widgets를 사용하여 Android에서 로그를 스크롤하세요.
* Advanced Flow에서 CSV, Excel 또는 JSON 다운로드용 임시 링크 생성.

이 앱은 플로우에 로깅 및/또는 알림을 추가할 수 있게 해줍니다. 선택적으로 로그에는 메시지 외에 앱/그룹, 심각도 및 시설을 포함할 수 있습니다.

여러 Syslog 클라이언트에 연결하여 a) 특정 메시지를 보내거나 b) 모든 기본 메시지(특정 심각도를 가진)를 보낼 수 있습니다.

그리고 마지막으로, 다른 Syslog 클라이언트들이 연결할 수 있도록 Syslog 서버 장치를 생성하면, 이는 Simple (Sys) Log에 기록됩니다.

로그를 메모리 대신 파일에 저장하여 더 많은 기록을 보관할 수 있습니다.

설정 페이지에는 Syslog 스타일의 인터페이스가 있으며, 여기서 할 수 있는 것들은 다음과 같습니다:
* 모바일이나 다른 가로 화면 장치에서 더 나은 시야를 위해 화면 회전.
* 특정 메시지, 날짜 등을 검색하고 필터링.
* 열 숨기기 또는 이동.
* 필터나 열을 기본값으로 저장.
* 모바일 앱, 웹 앱 또는 플로우 내에서 완전히 포맷된 Excel, Csv 또는 JSON 형식으로 로그 다운로드.

API 엔드포인트를 사용하여 로그에 액세스할 수 있습니다.

Better Logic Library를 지원합니다(기본 로깅에는 선택 사항이며, 전체 인터페이스, 내보내기 및 위젯에는 필수). 지원되는 Flow 메시지 및 그룹 필드에서 BLL 코드를 사용할 수 있습니다. 사용 방법은 Better Logic Library 앱 설정을 참조하세요.
