Новый и улучшенный Simple (Sys) Log.

Это приложение позволяет добавлять логирование и/или уведомления в ваши потоки.
Опционально лог может включать, помимо сообщения, приложение/группу, уровень серьезности и категорию.

Вы также можете подключаться к нескольким клиентам Syslog, чтобы а) отправлять определенные сообщения и б) отправлять туда все сообщения по умолчанию (с определенной степенью серьезности).

И последнее, но не менее важное, вы можете создать устройство Syslog Server, чтобы другие клиенты Syslog могли к нему подключаться, и оно будет записываться в Simple (Sys) Log.

Эта новая версия сохраняет логи в файлы, а не в память, обеспечивая гораздо больший лог, чем раньше.

Добавлена полностью новая страница настроек с интерфейсом в стиле Syslog, где вы можете:
* Поворачивать экран для лучшего просмотра на мобильном устройстве или устройстве с ландшафтным экраном.
* Искать и фильтровать конкретные сообщения, даты и т. д.
* Скрывать или перемещать столбцы.
* Сохранять фильтры или столбцы по умолчанию.
* Загружать полный лог в виде красиво оформленного Excel, Csv или JSON в мобильном приложении, инструментах для разработчиков или в потоках.


API

Может быть использованы следующие конечные точки API:
- Получить данные лога:
  GET /api/app/nl.nielsdeklerk.log/
- Добавить данные лога:
  PUT /api/app/nl.nielsdeklerk.log/addlog/
  Content-Type: application/json
  {"log": "Тест 1,2,3", "group": "ТЕСТ", "severity" : 6, "facility": 5, "timestamp":new Date() }
  * Только лог обязателен, остальное - опционально.
- Очистить лог
  GET /api/app/nl.nielsdeklerk.log/clearlog


* Это приложение по-прежнему функционирует как самостоятельное приложение, как и раньше, однако для включения всех функциональностей и нового интерфейса требуется установка Better Logic Library App.
